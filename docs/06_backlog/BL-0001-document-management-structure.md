## 1. 작업 목적

프로젝트 문서를 기준 문서, 계획, 분석, 작업 기록, 백로그, 참고 자료로 분리하고 일관된 작성·보관 규칙을 정착시킨다.

## 2. 범위

- 문서 관리 규칙과 표준 템플릿을 추가한다.
- Planning, Analysis, Worklog, Backlog의 인덱스와 초기 기록을 만든다.
- 기존 문서의 잘못된 링크와 중복 archive를 확인·정리한다.
- 기존 설계·거버넌스·참고 문서를 단계적으로 목표 경로에 배치한다.
- 전체 문서 지도와 최종 링크 검증을 완료한다.

## 3. 완료 조건

- 각 문서 유형의 경로·파일명·상태·인덱스 규칙이 문서화되어 있다.
- 초기 Backlog와 Worklog가 인덱스에 등록되어 있다.
- 활성 문서의 링크가 실제 경로와 일치한다.
- archive 문서의 보관 상태와 중복 여부가 명확하다.
- `docs/README.md`에서 현재 유효한 문서 구조를 찾을 수 있다.

## 4. 선행 조건과 위험 요소

- 문서 이동 전 현재 참조 경로와 archive의 차이를 확인해야 한다.
- 이동·삭제는 링크 검증과 별도 PR을 거쳐야 한다.
- 기준 설계 문서의 내용·승인 상태를 문서 구조 변경 과정에서 임의로 바꾸지 않는다.
