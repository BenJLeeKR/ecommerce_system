## 1. 작업 목적

로컬 AI 개발을 시작할 수 있도록 고객 웹, 관리자 웹, API와 공통 개발 도구의 최소 프로젝트 골격을 구성한다.

## 2. 범위

- 승인된 기술 스택을 기준으로 모노레포 구조를 확정한다.
- 로컬 실행, 테스트, 린트, 빌드의 기본 명령을 구성한다.
- 환경 변수 예시와 로컬 PostgreSQL 실행 방식을 문서화한다.

## 3. 완료 조건

- 고객 웹, 관리자 웹, API의 기본 실행 구조가 존재한다.
- 신규 개발자가 문서만으로 로컬 환경을 실행할 수 있다.
- 기본 테스트·린트·빌드 명령이 통과한다.

## 4. 선행 조건과 위험 요소

- 기술 스택과 아키텍처 설계의 승인 상태를 먼저 확인해야 한다.
- 외부 라이브러리 추가, DB 변경, 인증·주문·결제·재고 구현은 별도 승인 범위다.
