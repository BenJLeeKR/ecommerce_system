# 문서 템플릿 인덱스

- [Planning 템플릿](planning-template.md) — 큰 작업의 단계와 검증 계획을 작성한다.
- [Analysis 템플릿](analysis-template.md) — 조사 결과와 대안 비교를 작성한다.
- [Worklog 템플릿](worklog-template.md) — 수행 작업과 검증 결과를 기록한다.
- [Backlog 템플릿](backlog-template.md) — 작업 후보의 범위와 우선순위를 관리한다.
- [Task Contract 템플릿](task-contract-template.md) — Jules 작업의 범위·승인·검증 조건을 정의한다.
- [Project Profile 템플릿](project-profile-template.md) — 대상 프로젝트별 공통 통제 경계를 정의한다.
