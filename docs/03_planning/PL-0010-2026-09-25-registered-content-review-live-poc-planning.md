# PL-0010: Registered Content Review Live POC Planning (2026-09-25)

## 목적
등록된 Jules Plan 세션을 대상으로 Codex가 Pre-PR 수동 콘텐츠 검토 진입점을 사용자 지시 시 1회 적용하는 Live POC의 실행 계획과 비민감 결과 전달 방식을 기획합니다.

## 실행 계획

### 1. POC 진입 및 권한 통제
*   사용자의 명시적인 '조회 지시'가 있을 경우에만 Codex가 Pre-PR 수동 콘텐츠 검토(Live POC)를 호출합니다.
*   **Jules 제한 사항**: Jules 에이전트는 어떠한 경우에도 API, 외부 DB, 운영 또는 테스트 서버 경로에 접근할 수 없습니다.

### 2. 자동화 전면 금지
*   모든 자동화 프로세스(자동 승인, 자동 검토, 자동 병합, 자동 배포, 자동 재시도, 자동 재작업)는 원천적으로 금지됩니다.

### 3. 비민감 결과 전달 및 기록
*   **민감 정보 차단**: Plan 원문, 프롬프트, 활동, 로그, 세션 식별자, API/DB 접근 정보, 비밀값 등은 문서, PR, Worklog에 절대 포함되지 않습니다.
*   **전달 방식**: 실제 Live POC 호출 후, Codex는 Jules에게 오직 '비민감 결과(성공/안전 중단 여부 및 고정 사유 코드)'만을 전달합니다.
*   **기록 원칙**: Jules는 이 비민감 결과를 전달받은 후에만 POC 결과를 문서에 기록하며, 결과가 아직 없는 경우에는 성공이나 실패를 추정하거나 완료로 기록하지 않습니다.

### 4. 사후 1:1:1 결속 및 인계
*   Jules가 허용된 6개 파일만 변경하여 단일 브랜치 및 PR을 준비하면, PR 본문 작성 및 수정의 책임은 Codex에게 인계됩니다.
*   Codex는 사후에 해당 세션, 브랜치, PR 간의 1:1:1 결속을 확인하고 기록합니다. Jules는 예상되는 브랜치명 등을 사전에 문서화하거나 예측하여 사용하지 않습니다.
